## 📌 Overview

The **Interview Drill App** is a full-stack web platform designed to help candidates prepare for job interviews through **structured, repetitive practice sessions** that mirror real hiring scenarios.

Unlike static Q&A banks, this app focuses on **drilling** — adaptive, targeted practice that exposes and closes knowledge gaps across multiple industries.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎯 **Adaptive Question Sets** | Targets weak areas based on session performance |
| 🏭 **Multi-Industry Coverage** | Tech, Finance, Consulting, General roles |
| 📊 **Session Tracking** | Monitors progress across practice sessions |
| 🔄 **Drill Mode** | Repetitive, targeted practice on flagged topics |
| 📱 **Responsive UI** | Works seamlessly on desktop and mobile |

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Bharathraj6868/Interview--Drill-app.git

# Navigate to project directory
cd Interview--Drill-app

# Install dependencies
npm install

# Start the development server
npm run dev
```
